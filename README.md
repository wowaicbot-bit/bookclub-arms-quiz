# 팔은 거짓말을 못 한다 · 실루엣 퀴즈

『FBI 행동의 심리학』(조 내버로) **팔 편** 독서모임 발표용 8문항 퀴즈입니다.

👉 **[퀴즈 열기](https://wowaicbot-bit.github.io/bookclub-arms-quiz/)**

## 진행 방법

**방 만들기** 를 누르면 6자리 코드가 나옵니다. 참가자들이 같은 주소에서 그 코드를 넣으면,
참가자 화면이 진행자를 따라 움직이고 각자 고른 답이 실시간으로 집계됩니다.

혼자 넘겨보거나 인터넷이 없는 곳에서는 **혼자 진행** 을 쓰면 됩니다.

### 실시간은 어떻게 동작하나

전용 서버가 없습니다. 공개 MQTT 브로커(EMQX·HiveMQ·Mosquitto)에 방 코드로 된
주제를 만들어 주고받습니다. 가입도 키도 필요 없고, 한 곳이 막히면 다음 브로커로 넘어갑니다.

다만 공개 브로커라 **방 코드를 아는 사람은 누구나 집계를 볼 수 있습니다.**
가벼운 퀴즈용으로만 쓰시고, 민감한 내용은 올리지 마세요.

| 키 | 동작 |
|---|---|
| `→` / `Space` | 정답 공개 → 다음 |
| `←` | 이전 |
| `N` | 진행자 노트 (발표자용 멘트) |

특정 문제로 바로 가려면 주소 뒤에 번호를 붙입니다.
`#3` 은 3번 문제, `#3a` 는 정답까지 펼친 상태입니다. 리허설할 때 편합니다.

## 문항

1. **열림과 닫힘** — 승리 vs 실축. 기준은 높이가 아니라 부피
2. **영역 선언** — 테이블을 차지한 쪽이 책임자
3. **함정** — 같은 뒷짐, 선택이면 지배 / 강요면 복종 (정답은 "알 수 없다")
4. **팔짱의 진실** — 방어가 아니라 자기 위로일 수 있다. 구분은 손가락
5. **서점 CCTV** — 보이지 않으려는 노력이 가장 눈에 띈다
6. **같은 사람, 1분 차이** — 자세가 아니라 변화를 보는 것이 이 책의 사용법
7. **거리** — 팔의 거리가 곧 허용한 거리
8. **마지막 함정** — 양손 허리는 유효하지만, 파워 포징은 재현에 실패했다

3번과 8번은 책을 그대로 따르지 않고 **의심해보는** 문항입니다.

## 그림에 대해

실제 인물 사진은 쓰지 않았습니다. 전부 코드로 그린 SVG 실루엣입니다.
얼굴이 아예 없으니 "팔만 보고 판단한다"는 목적에 더 맞습니다.
